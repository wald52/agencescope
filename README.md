# Agencescope — Le radar des 1244 agences de l'État

**434 opérateurs** (LOLF), **~700 ODAC** (INSEE), **1244 agences vision large** (IGF). **73,3 Md€** PLF 2026, **482 000** ETPT.

- **Expert pour vérifier** : budget détaillé en 8 colonnes, trésorerie, immobilier, top 10 rémunérations, sources
